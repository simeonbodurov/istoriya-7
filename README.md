# Часът по история — генериран сайт

Тази папка съдържа **готовия за публикуване сайт**. Всичко в нея се създава автоматично от `build.py`.

> ⚠️ **Не редактирайте файловете тук.** При следващото сглобяване промените ще бъдат изтрити.
> Текстът на книгата се пише в `../chapters/`.

**Състояние:** генерирани са 16 от 48 глави (33 %), последната е № 16. Обновено на 15.08.2026 г.

---

## Публикуване в GitHub Pages

1. **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` · **Folder:** `/docs`
4. След минута сайтът е достъпен на `https://<потребител>.github.io/<хранилище>/`

Файлът `.nojekyll` изключва обработката с Jekyll — нужен е, за да се сервират страниците както са.

---

## Какво има в папката

| Файл | Какво е |
|---|---|
| `index.html` | съдържание, групирано по раздели, с напредък и „продължи оттам, докъдето стигна“ |
| `glava-NN.html` | по една страница за всяка глава |
| `plan.html` | планът на книгата (**съдържа спойлери**) |
| `style.css` | стилове за четене на телефон, с тъмна тема |
| `app.js` | размер на шрифта, лента с напредъка, отметки за прочетено |
| `chapters.json` | списък на главите в машинночетим вид |
| `.nojekyll` | изключва Jekyll |

Няма външни зависимости: без сървър, без база данни, без шрифтове от интернет. Сайтът работи и офлайн, ако папката се отвори локално.

